# Prazo.

Mural de trabalhos e provas da faculdade que roda 100% no navegador: cadastre prazos por disciplina, acompanhe o que está atrasado, vence hoje ou nesta semana, e marque como entregue.

**🔗 Demo:** https://furlani18.github.io/prazo/

## Funcionalidades
- Cadastro de prazos com tipo, disciplina, data, prioridade e descrição
- Painel com atrasados, vencendo hoje, da semana e pendentes
- Busca e filtros por status, tipo e disciplina, com ordenação
- Notas e disciplinas
- Exportar e importar os dados

Sem servidor: tudo fica salvo no próprio navegador (localStorage).

## Tecnologias
HTML · CSS · JavaScript · localStorage
